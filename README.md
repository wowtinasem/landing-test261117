# 아이콘랩 강사 소개 홈페이지

바이브코딩 전문강사 · 기업 AX컨설턴트 · NCS강사 **아이콘랩**의 한 페이지 소개 사이트입니다.
(샘플 강의용으로 만든 예시이며, 숫자·후기·주소는 샘플 값입니다.)

- 사이트: https://landing-test261117.netlify.app
- 문의: 010-3409-6116

## 파일 구조

```
index.html           페이지 내용 (섹션 순서: 히어로 → 숫자 → 소개 → 강의 → 경력 → 후기 → 문의 → 푸터)
css/style.css        디자인 (맨 위 :root 에서 색상을 한 번에 바꿀 수 있어요)
js/main.js           움직임 (햄버거 메뉴, 타이핑, 숫자 올라가기, 스크롤 등장, 이메일 조합)
images/              그림 (토끼 아바타, 강의 일러스트, 미리보기 그림, 파비콘)
netlify.toml         Netlify 배포·보안 헤더 설정
```
